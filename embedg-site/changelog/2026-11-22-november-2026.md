Forms arrived, messages can carry polls, and there are two new tools for timestamps and Discord IDs.

<!--truncate-->

- **Forms.** Forms are pop-ups that ask members to type an answer or pick options, members, roles, or channels. A button, select menu, or custom command opens one with the Show Form action, and the answers can go into the reply. Every server gets 3 forms for free, 10 with Embed Generator Premium, and 25 with Ultimate. See [Forms](/docs/guides/forms).
- **Form answers for your team.** Post Answers to a Channel sends every answer to a staff channel, and Send Answers to URL passes them to Zapier, n8n, Make, or your own server. Both need Premium. See [Sending answers to other tools](/docs/guides/forms#sending-answers-to-other-tools).
- **Polls.** A message can carry a poll with up to 10 answers, shown below the embeds. See [Polls](/docs/features/polls).
- **Timestamp Generator.** Pick a date, time, and timezone and copy a timestamp that shows in each reader's own timezone. Open the [Timestamp Generator](https://message.style/app/tools/timestamps).
- **Snowflake Decoder.** Paste any Discord ID to see when it was created, or turn a date into an ID. Open the [Snowflake Decoder](https://message.style/app/tools/snowflake).
- **Discord's new text colors.** The [Colored Text Generator](https://message.style/app/tools/colored-text) uses the colors Discord switched to in August, and adds italic and strikethrough.
- **Phishing protection for Embed Links.** Embed Links can't lead to sites on the phish.sinking.yachts list or go through link shorteners. A link whose site is added to the list later shows "Link blocked" in Discord.
- **A line under link previews.** Embed Links with a custom component now end with a "Link preview from message.style" line, so a link can't pass as the poster's own message. It's left out of links created by someone who bought Premium or Ultimate.
- **Files in the preview.** Attachments show up in the editor's preview, and File components have a paperclip button that attaches the file.
- **Time of sending.** An embed's timestamp can be the time the message goes out instead of a fixed date.
- **Select menus that reset.** Turn on Clear after use and a select menu goes back to its placeholder after each pick, so members can pick the same option twice.
- **Install the app.** Embed Generator can be installed from the browser like an app, on desktop and on phones.
- **Message dumps as a file.** /message dump and the Dump Message context menu now attach the message as a JSON file.
- **Smaller fixes.** Threads and forum posts are collapsed under their channel in the channel list. The emoji picker shows the emojis of the server you picked. Cmd+Z and Cmd+Shift+Z undo and redo on a Mac. Dates in the preview use your own date format. Code blocks show correctly in the preview. The sidebar scrolls on short screens.

Try it all in the [editor](https://message.style/app/editor).
