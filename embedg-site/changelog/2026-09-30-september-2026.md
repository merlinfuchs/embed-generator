The AI assistant became a chat that edits your message, and webhooks can now send link buttons and Components V2 layouts without the bot.

<!--truncate-->

- **AI assistant as a chat.** The assistant now sits next to the editor. Describe what you want and it edits the whole message, then keep asking for changes. Free servers get 5 prompts a month. See [AI assistant](/docs/features/ai-assistant).
- **Templates for new messages.** Starting a new message opens a dialog with 6 templates, a blank message, and the AI assistant. It starts in Components V2, and you can switch to embeds.
- **Layouts and link buttons through webhooks.** Messages sent through a webhook can now include link buttons and every Components V2 layout. Only buttons and select menus with actions still need the bot. See [Webhook or Channel?](/docs/guides/send-modes).
- **Fluxer webhooks.** Paste a Fluxer webhook URL to send, edit, and restore messages there. See [the announcement](/blog/fluxer-embeds).
- **Scheduled messages that edit.** A scheduled message can edit an existing message on each run instead of sending a new one. Each schedule also has its own timezone now, so admins in other countries see the same times. See [Scheduled Messages](/docs/guides/scheduled-messages).
- **Choose who gets pinged.** The cog in the editor's menu bar opens Message Settings, where you pick whether users, roles, and @everyone get pinged.
- **Voice, stage, and media channels.** The channel list now includes voice, stage, and media channels. Messages go to the text chat of voice and stage channels, and they start a new post in media channels, like in forums.
- **Formatting in text displays.** The bold, italic, mention, and emoji buttons now work in Components V2 text displays.
- **Clearer permission errors.** When the bot or you can't reach a server or channel, the editor says which permission is missing and who's missing it.

Try it all in the [editor](https://message.style/app/editor).
