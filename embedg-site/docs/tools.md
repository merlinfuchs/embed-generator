# Tools

Besides the message editor, Embed Generator has a few small free tools. Most of them need no account; the User Lookup needs you to log in with Discord.

## Colored Text Generator

Discord renders ANSI color codes inside code blocks. The [Colored Text Generator](https://message.style/app/tools/colored-text) lets you type your text, pick foreground and background colors per word, and copy the result as a code block you can paste into any Discord message.

## Embed Links

[Embed Links](https://message.style/app/tools/embed-links) turn a title, description, image and color into a URL. When that URL is posted in Discord, it unfurls into an embed, so you can share a rich preview without a webhook or bot. Only a subset of embed fields is supported, since Discord builds the preview from the page's meta tags. Links can't lead to known phishing sites or go through link shorteners like tinyurl.com, since a shortener hides where a link goes.

Turning on **Custom Component** replaces that preview in Discord with a Components V2 layout: markdown text, images, galleries, separators and link buttons. The fields above stay as the fallback for everywhere else and for Discord clients that can't render it. The layout ends with a small "Link preview from message.style" line. It's left out of links you create while logged in, once you've bought Premium, Ultimate, or the [one-time removal](https://message.style/premium/embed-links).

## Webhook Info

Paste any Discord webhook URL into [Webhook Info](https://message.style/app/tools/webhook-info) to see the webhook's name, avatar and who created it. Handy when you find an old URL and don't remember what it was for.

## User Lookup

Paste a Discord user ID, or a mention, into [User Lookup](https://message.style/app/tools/user-lookup) to see the user's name, avatar, banner, accent color, public badges and when their account was created. Discord only gives these details to bots, so the lookup runs on our server and you need to log in with Discord to use it. Each person can do up to 30 lookups a minute, and results are cached for a few minutes.
